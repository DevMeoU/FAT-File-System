Yêu cầu:
Khi mount file system, nếu file system không hợp lệ, chương trình sẽ hiển thị thông báo lỗi và thoát.
Nếu path không tồn tại, chương trình sẽ hiển thị thông báo lỗi và thoát.
Nếu path không phải là img file, chương trình sẽ hiển thị thông báo lỗi và thoát.
Nếu mount thành công, chương trình sẽ hiển thị thông báo và chuyển sang chế độ shell.
Khi mount thành công, nếu path truyền vào là '/' thì chương trình sẽ chuyển sang chế độ root.
Khi mount thành công, nếu path truyền vào không phải là '/' thì chương trình sẽ chuyển sang chế độ user.
Khi chuyển sang chế độ root, chương trình sẽ hiển thị thông báo và chuyển sang chế độ root.
Khi chuyển sang chế độ user, chương trình sẽ hiển thị thông báo và chuyển sang chế độ user.
Khi mount thành công, phân tích path để tìm ra đường dẫn thực sự của file hoặc thư mục.
Khi mount thành công, nếu path đang là '/' và command là 'ls' thì chương trình sẽ hiển thị toàn bộ file và thư mục trong root.
Khi mount thành công, nếu path đang là '/' và command là 'cd' thì kiểm tra xem path có phải là thư mục không, nếu không thì hiển thị thông báo lỗi và thoát.
Khi mount thành công, ví dụ path là '/abc/def', command là 'ls' thì chương trình sẽ hiển thị toàn bộ file và thư mục trong /abc/def.
Khi mount thành công, ví dụ path là '/abc/def', command là 'cd' thì kiểm tra xem path có phải là thư mục không, nếu không thì hiển thị thông báo lỗi và thoát.
Khi mount thành công, ví dụ path đang không phải là '/' và command là 'cd ..' hoặc 'cd ../' thì chuyển sang thư mục cha.
Khi mount thành công, ví dụ path đang không phải là '/' và command là 'cd ../abc' hoặc 'cd ../abc/' thì chuyển sang thư mục abc ở thư mục cha.
Khi mount thành công, ví dụ path đang không phải là '/' và command là 'cd ../abc/def' hoặc 'cd ../abc/def/' thì chuyển sang thư mục def ở thư mục abc ở thư mục cha.
Khi mount thành công, ví dụ path đang không phải là '/' và command là 'cd ../abc/def/ghi' hoặc 'cd ../abc/def/ghi/' thì chuyển sang thư mục ghi ở thư mục def ở thư mục abc ở thư mục cha.
Khi mount thành công, ví dụ path đang không phải là '/' và command là 'cd .' hoặc 'cd ./' thì chuyển sang thư mục hiện tại.
Khi mount thành công, ví dụ path đang không phải là '/' và command là 'cd /' thì chuyển sang thư mục root.
